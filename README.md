# dotfiles

Personal shell environment backup. Zsh + oh-my-zsh + Powerlevel10k, with a
Homebrew-based toolchain.

## What's in here

| File | Purpose |
|------|---------|
| `.zshrc` | Main zsh config: oh-my-zsh, plugins, aliases, brew/nvm/zoxide setup |
| `.p10k.zsh` | Powerlevel10k prompt configuration (generated by `p10k configure`) |
| `.gitconfig` | Git identity — **update name/email after cloning** |
| `install.sh` | Bootstrap script for a fresh machine (installs deps + symlinks) |
| `.gitignore` | Keeps secrets/credentials out of the repo |

> **Not backed up on purpose:** SSH/GPG keys, `~/.claude/`, cloud credentials,
> shell history, and anything matched by `.gitignore`. `.bashrc` is omitted
> because it's the unmodified Ubuntu default.

## Quick start on a new Ubuntu 26.04 VM

```bash
git clone <your-repo-url> ~/dotfiles
cd ~/dotfiles
./install.sh
exec zsh
```

That's it — `install.sh` handles everything below.

## What `.zshrc` depends on (prerequisites)

A bare Ubuntu install does **not** have these; the `.zshrc` will throw errors
on nearly every line without them. Order matters — brew and oh-my-zsh must
exist before `.zshrc` is sourced.

1. **zsh** + `git`, `curl`, `build-essential` — `apt`
2. **Homebrew (linuxbrew)** at `/home/linuxbrew/.linuxbrew` — hardcoded in `.zshrc`
3. **oh-my-zsh** — `source $ZSH/oh-my-zsh.sh`
4. **Powerlevel10k** — cloned into `$ZSH_CUSTOM/themes/powerlevel10k`
5. **nvm** — installed via brew (`.zshrc` loads it from the linuxbrew path)
6. **eza, bat, zoxide** — via **brew** (see the `bat` note below)
7. **zsh-autosuggestions, zsh-syntax-highlighting** — via **apt** (`.zshrc`
   sources them from `/usr/share/...`)
8. A **Nerd Font** (e.g. *MesloLGS NF*) set in your terminal — the p10k prompt
   was built with `nerdfont-v3`

### ⚠️ The `bat` gotcha
`.zshrc` has `alias cat="bat"`. Install `bat` via **brew** (binary is `bat`).
Ubuntu's `apt` package installs it as **`batcat`**, which would break the alias.

### Plugins
`plugins=(git golang httpie jj kubectl rust tmux alias-finder bun docker docker-compose)`
— most ship with oh-my-zsh. `jj` and `bun` only add completions; if those tools
aren't installed zsh prints a harmless warning. Add them with
`brew install jj bun` if you use them.

## First-time backup (initialize this repo and push)

These need a real terminal (git/network). From this folder:

```bash
git init
git add -A
git commit -m "Initial dotfiles backup"
git branch -M main

# Option A — with the GitHub CLI:
gh repo create dotfiles --private --source=. --push

# Option B — manual remote:
git remote add origin git@github.com:<your-username>/dotfiles.git
git push -u origin main
```

## Updating the backup later

Because `install.sh` symlinks the files, editing `~/.zshrc` edits the repo copy
directly. To save changes:

```bash
cd ~/dotfiles
git add -A && git commit -m "tweak shell config" && git push
```

To refresh `.p10k.zsh` after running `p10k configure`, just commit it again —
`p10k` writes through the symlink back into this repo.
